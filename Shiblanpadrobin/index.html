ShibLaunchpad 全局设置
所有权
把整个 Launchpad 合约的"管理员权限"转给别人。转出去之后，你就不能再改任何设置了，新地址才是老大。
--
平台设置
Platform Recipient：平台手续费的收款地址。每次交易产生的手续费，平台抽成的那部分会打到这个地址。
Factory：告诉 Launchpad "哪个合约有资格调用我"。只有这个 Factory 合约才能触发发币流程。
Hook：V4 池子的"门卫"合约，控制谁能加/撤流动性。防止别人随便撤池子。
--
费率分配
设置手续费的分成比例。Platform BPS 是平台拿多少，Reward BPS 是分红池拿多少。比如 4000/6000 就是平台拿 40%，分红池拿 60%。两个加起来必须等于 10000。
交易参数
Slippage：滑点保护。回购分红代币时，如果实际成交价比预期差太多，交易就会失败，防止被套利。
TWAP Band：TWAP 偏差容忍度。回购时会拿实时价格和 TWAP 均价对比，偏差超过这个范围说明价格被操控了。
TWAP Window：TWAP 的时间窗口（秒）。默认 1800 就是看过去 30 分钟的平均价格。窗口越长越不容易被操控。
V3 Buyback Fee：用 Uniswap V3 回购分红代币时选的池子费率。
Min Buyback ETH：最低回购金额。累积的手续费 ETH 要达到这个数才能触发回购，太小的金额不值得花 gas。
分红黑名单
把某个地址加进去，这个地址就永远拿不到分红。一般用来封禁合约自身、黑洞地址等不该参与分红的地址。
预估价格
手动设置某个分红代币的预估价格。当没有配置 TWAP 池子时，系统用这个价格来算最低回购量，防止滑点过大。
Buyback Pool 配置
配置用哪个池子来回购分红代币。可以选 V3 或 V4 的池子，指定费率和 Hook。如果某个分红代币没有配置专属池子，就默认走 V3 的 buyback fee 池子。
Rescue ERC20
紧急救援。如果有 ERC20 代币误转到 Launchpad 合约里了，用这个功能把它转到指定地址。只能救援还没发币的代币，已发币的不行（防止误操作影响池子）。

修改 Creator
改某个币的 creator 地址。creator 是领取 token 手续费的人，改了之后手续费就打给新地址。
代币级 TWAP / Slippage / Fee
给某个币单独设参数，覆盖全局设置。TWAP Pool：配一个专属的 TWAP 参考池子，回购时用这个池子的均价校验价格，更精准。留空就是清除，回退到全局。TWAP Band / Slippage / Buyback Fee：分别覆盖全局的偏差容忍度、滑点、回购费率。
修改 Dividend Token / Tracker
Dividend Token：改某个币的分红代币。比如原来用 ETH 分红，现在想改成用另一个 ERC20 分红。改了之后 TWAP 池子会被清空，需要重新配。
Tracker：改某个币的分红追踪器合约地址。一般不需要改，除非 Tracker 合约要升级。
操作
collectFees：从 V4 池子里把累积的手续费（ETH + token）收到 Launchpad 里。
buybackAndDistribute：用收到的 ETH 去回购分红代币，然后分给所有持币人。
payCreator：把累积的 token 手续费打给 creator。
processAll：一键执行上面三步，哪步失败不影响其他步骤。
bookStrayEth：如果链上有"无主"的 ETH 转到 Launchpad，用这个把它记到某个币的 pending 里，让它参与回购分红。

提取
把 Factory 合约里误收到的 ETH 或 ERC20 代币提走。
Claim Platform Fee
领取 Launchpad 里累积的、还没成功打出去的平台手续费 ETH。有时候打款会失败（比如收款地址是合约且拒绝接收），ETH 会暂存在这里，用这个按钮重新领取。
