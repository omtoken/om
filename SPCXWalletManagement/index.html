转让所有权 (两步验证)

两步转让：先发起转让请求，新 Owner 需要调用"接受所有权"来确认。只有当前 Owner 可以操作。

接受所有权

如果您是 pendingOwner，可以调用此函数接受所有权。只有被指定的 pendingOwner 可以操作。

提取 BNB

提取指定数量的 BNB 到目标地址。仅 Owner 可操作。

提取全部 BNB

将合约中所有 BNB 提取到目标地址。仅 Owner 可操作。

提取 ERC20 代币

提取指定数量的 ERC20 代币到目标地址。仅 Owner 可操作。

输入代币的最小单位数量。例如 USDT (18位精度) 1个 = 1000000000000000000
提取全部 ERC20 代币

将合约中指定代币的全部余额提取到目标地址。仅 Owner 可操作。

预览分配

查看当前合约 BNB 按 NFT 持有情况的分配预览，不会实际执行分配。

执行 BNB 分配

将合约中的 BNB 按 NFT 持有数量比例分配给所有符合条件的持有者。任何人都可以调用此函数。分配时会自动跳过隔离地址。

添加单个隔离地址

将地址加入隔离列表，该地址将不参与 BNB 分配。仅 Owner 可操作。

批量添加隔离地址

一次添加多个隔离地址，每行一个地址。仅 Owner 可操作。

移除隔离地址

将地址从隔离列表中移除，恢复其参与 BNB 分配的资格。仅 Owner 可操作。

查询隔离地址

查看当前所有隔离地址列表，或检查某个地址是否已被隔离。

设置起始 Token ID

修改 NFT 扫描的起始 Token ID。默认为 1。仅 Owner 可操作。

设置分配 Gas 限制

修改分配 BNB 时每个地址的 Gas 限制。范围: 2300 ~ 500,000。默认 60,000。仅 Owner 可操作。

最小值 2300，最大值 500000
